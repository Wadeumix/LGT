# らぶぐらっGT ルールブック

**らぶぐらっGT** は、レース文化および車両文化の発展を目的として開催される長期シリーズ型レースイベントです。

本ルールブックは、大会に参加するすべてのチーム・選手・ピットクルーが遵守すべき規則をまとめたものです。

{% hint style="info" %}
本大会は単発レースではなく、**全3戦で構成されるシリーズ戦**として実施されます。各レースの順位に応じてポイントを付与し、全3戦終了時点での合計ポイントによって総合順位を決定します。
{% endhint %}
