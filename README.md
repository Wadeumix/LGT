# LGT OBS レイアウト

配信用オーバーレイ(リーダーボード ⇔ チーム名簿を自動切り替え)。

## ファイル構成

- `index.html` — レイアウト本体
- `style.css` — 見た目(色・フォント・配置)
- `data.js` — **表示内容(順位・チーム名・メンバー)はここだけ編集すればOK**
- `script.js` — 自動切り替えのロジック(通常は編集不要)

## OBSでの設定方法

1. OBSで「ソースを追加」→「ブラウザ」を選択
2. 「ローカルファイル」にチェックし、この `index.html` を指定
3. 幅・高さは実際のオーバーレイサイズ(720px前後)に合わせて設定
4. 背景は透過なので、そのまま配信画面に重ねて使えます

## 内容を更新したいとき

`data.js` の `LEADERBOARD`(順位表)と `ROSTERS`(チームごとのメンバー一覧)を書き換えてください。ブラウザソースを更新(右クリック→更新)すると反映されます。
