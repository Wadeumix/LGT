# 2. 参加条件・チーム登録

## 2-1. 参加条件

参加チームは、以下の条件をすべて満たしているものとする。

* 選手として最低2名のメンバーが所属していること
* ピットクルーとして、選手とは別にメカニックが所属していること
* 参加費（1,000万）の支払いが可能であること
* らぶぐらっGT運営より参加承認を受けていること

## 2-2. チーム登録ルール

チーム登録における最少人数は、以下の通りとする。

| 役割 | 最少人数 |
| --- | --- |
| レーサー | 2名 |
| ピットクルー（メカニック） | 1名 |

* 上記最少人数を超えるメンバー登録は可能とする。
* シーズン期間中は、選手の交代を認める。
* レーサーとして出場する選手2名については、原則として母体企業の従業員は**1名まで**とする。
