# 7. 抗議・審議・ペナルティ

## 7-1. 抗議・審議ルール

{% hint style="danger" %}
全選手は、レース開始から終了まで**ボディカメラの装着および録画を義務**とする。録画データは、レース終了後速やかに「らぶぐらっGT」Discordサーバーへ提出しなければならない。
{% endhint %}

* 故意の接触、危険行為、妨害行為などが発生した場合、対象チームは運営へ抗議申請を行うことができる。
* 運営は提出されたボディカメラ映像をもとに審議を行い、必要に応じて裁定およびペナルティを決定する。
* 強制瞑想等でレースが続行不可となった場合には、運営側で補填や再走・順位調整などは行わないものとする。

## 7-2. ペナルティ制度

* 抗議および審議の結果、故意の接触や悪質な妨害行為が確認された場合、加害チームに対してシリーズポイントの減点ペナルティを科す。
* 減点数については、違反行為の悪質性や影響度をもとに運営が判断する。
