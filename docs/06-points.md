# 6. ポイント・賞金・ハンデ

## 6-1. ポイント制度

各レース終了時、順位に応じて以下のシリーズポイント (SP) を付与する。

| 順位 | シリーズポイント (SP) |
| --- | --- |
| 1位 | 22 SP |
| 2位 | 16 SP |
| 3位 | 12 SP |
| 4位 | 8 SP |
| 5位 | 6 SP |
| 6位 | 4 SP |
| 7位 | 2 SP |
| 8位 | 1 SP |

{% hint style="warning" %}
SP配分については、シーズン開始前に変更される場合がある。
{% endhint %}

## 6-2. 賞金

チーム数次第。

## 6-3. ハンデ制度

各レースにおいて優勝したチームには、次戦で使用可能なパフォーマンスカスタムポイントを **「3 PP減少」** させるハンデを適用する。
