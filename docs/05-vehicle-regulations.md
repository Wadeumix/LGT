# 5. 車両レギュレーション

## 5-1. 使用車両について

使用可能車両は、**バニラ車両のみ**とする。

## 5-2. 車両のカスタマイズについて

本戦で使用する車両のパフォーマンスカスタムについては、各チームに **「8 PP（パフォーマンスポイント）」** を付与する。

以下の項目について、1レベルごとに1 PPを消費してカスタムを行うことができる。

* エンジン
* ブレーキ
* トランスミッション
* サスペンション
* アーマー

{% hint style="info" %}
スタンス調整については、街のルールの範囲内であれば制限を設けない。
{% endhint %}

## 5-3. シーズン中の本戦車両の変更について

* シーズン期間中に本戦用車両を変更する場合、チームは運営へ変更申請を行い、変更費用として**500万**を支払うものとする。
* 車両変更の申請期限は、対象レース開催日の**3日前まで**とする。
