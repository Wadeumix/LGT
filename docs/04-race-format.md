# 4. レース形式

## 4-1. 当日予選レース

各チーム代表者1名が当日予選レースを走行する。

* **Q1**：出走タイミングをずらし、タイムアタック形式で走行。上位数チームをQ2進出とする。
* **Q2**：上位の順位を決定する。
* 決勝レースのスターティンググリッドは、この当日予選のタイムをもとに決定する。

## 4-2. 決勝レース

2名1組による**リレー形式**で実施する。

ドライバー交代時には必ずピットインを行い、ピットクルーによる作業を実施しなければならない。

### ピット作業（必須作業）

以下を必須作業とし、実施するものとする。

* ジェリ缶1本分の燃料補給
  * 車側が満タンになった場合はジェリ缶を使い切る必要はない
* タイヤ整備
* ブレーキ整備

{% hint style="info" %}
外装修理については必要に応じて実施すること。
{% endhint %}

### レース形式による違い

**サーキット形式のレースの場合**

規定周回数を消化した時点から、ピットインおよびドライバー交代を可能とする。

**スプリント形式のレースの場合**

コース中に設定された中継地点にて、ピット作業およびドライバー交代を行うものとする。
